# lehopt

lehopt: Luke (E.) Hiester's little attempt at an optimization package.

Currently this package is primarily intended as a vehicle for learning and
experimentation for myself. Maybe it will eventually be practically useful
for some things. We'll see!

This package will follow semantic versioning. However, note that it is
currently in 0.x, and no backwards compatibility should be assumed across
versions prior to a 1.0 release. At the current stage of development,
backwards compatibility is *likely* to be broken in many places as the
design solidifies.

## LLM policy

A definitive policy has not yet been adopted for use of large language
model output in the implementation of this package, because none has been
used thus far. In the event that LLM output is used, this section will be
updated with the testing and verification practices followed.
